Token Island

Une encoche en haut de l'écran qui compte les tokens consommés chez Claude, GPT, Gemini, Grok et les autres.

1. Brancher tes outils sur le proxy local

Le proxy transmet tes requêtes telles quelles à l'API officielle et lit le nombre de tokens dans la réponse. Tes clés d'API restent dans tes outils : l'app ne les lit pas et ne les enregistre pas. Il suffit de changer l'adresse de base de l'API dans l'outil ou le script :

Variables d'environnement Windows (PowerShell, pour l'utilisateur courant ; rouvre ensuite ton terminal) : 


        
        

          Pour nommer l'outil dans l'encoche, ajoute l'en-tête X-Token-Island-App: MonScript à tes requêtes.
          Les abonnements web (claude.ai, chatgpt.com, gemini.google.com, grok.com) ne passent pas par une API et ne
          peuvent pas être comptés ainsi.

3. API d'administration (facultatif)

        

          Elles voient toute la consommation de ton organisation, même celle qui ne passe pas par le proxy (Cursor, serveurs…),
          avec quelques minutes de retard. Quand l'une est active, les requêtes du même fournisseur vues par le proxy ne
          sont plus comptées, pour éviter le double comptage.
